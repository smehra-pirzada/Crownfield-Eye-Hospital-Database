# Crownfield-Eye-Hospital-Database
Database design and implementation for Crownfield Eye Hospital using MySQL
## Project Overview 
This database manages patient records, appointments, diagnoses, prescriptions and follow-up plans for Crownfield Eye Hospital.

## Repository Contents
- Database export containing tables, constraints and synthetic data.
- Part C SQL queries, stored procedure and trigger.
- Part D security roles, permissions and hashing demonstration.

## How to Run
Import the database export using MySQL Workbench in a separate test environment. Run the individual query and security statements as required. The database restoration has not yet been tested. 

## Data Protection
All patient data is fictional and is used for educational purposes only.
